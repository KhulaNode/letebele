# Letebele Pharmacy website MVP

Static, crawlable site for the two Letebele Pharmacy branches in Polokwane. Customers can browse products and listed prices, then send collection orders directly to the pharmacy on WhatsApp. The site has no checkout, payment, delivery, booking, live-stock integration, medical intake, diagnosis or prescribing feature. If an item becomes unavailable after an order, the pharmacy contacts the customer directly.
